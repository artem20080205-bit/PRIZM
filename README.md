# PRISM

Настольный чат для двух участников на Electron и Node.js. Один компьютер хранит историю и файлы. Второй подключается по приглашению через HTTPS. Временный публичный адрес создаёт Cloudflare Tunnel. Сквозного шифрования пока нет.

## Установка на Windows

Понадобятся [Node.js 24 или новее](https://nodejs.org/) и [Git](https://git-scm.com/).

Первый запуск:

```powershell
git clone https://github.com/artem20080205-bit/PRIZM.git
cd PRIZM
.\start.cmd
```

При первом запуске скачиваются зависимости и Electron. Можно запускать приложение двойным щелчком по `start.cmd`.

### Переход с Python-версии 0.3.1

Закройте старый PRISM на обоих ПК. В папке существующей Git-копии выполните `git pull --ff-only`, затем запустите `start.cmd`. Для обновлений после первого перехода используйте `update.cmd`.

Приложение читает прежние `preferences.json`, `client_state.sqlite`, серверную базу `server.sqlite` и папку вложений `files`. При запуске сервера укажите **прежнюю папку данных** (обычно `server_data_v02`). Если старая версия была распакована отдельно, её серверная папка может находиться вне новой Git-копии. Используйте путь к ней. Старый и новый серверы должны работать с этой папкой по очереди.

Клиенты 0.3.1 и Node.js используют протокол 3. Приглашения с префиксами `prism:` и `lantern:` принимаются, пока указанный в них сервер и адрес доступны.

## Подключение с другого ПК

1. На компьютере хозяина нажмите **Создать сервер**, выберите папку данных и нажмите **Запустить**.
2. Нажмите **Включить интернет**. Когда станет доступна кнопка **Приглашение другу**, скопируйте приглашение.
3. На втором ПК нажмите **Подключиться** и вставьте приглашение. При перезапуске туннеля отправьте новое приглашение.

Windows x64 при первом включении интернета скачивает зафиксированную версию `cloudflared` и сверяет SHA-256. На других платформах установите [cloudflared](https://developers.cloudflare.com/cloudflare-one/networks/connectors/cloudflare-tunnel/downloads/) в `PATH` или задайте полный путь в переменной `PRISM_CLOUDFLARED`. Если канал не запускается, посмотрите `tunnel.log` в папке проекта.

## Файлы и хранилище

Оба участника могут прикреплять и скачивать файлы. При сбое отправка продолжится с байта, сохранённого сервером. Если попытки восстановления исчерпаны, выберите тот же файл. Чтобы продолжить прерванное скачивание, выберите тот же путь сохранения.

**Отменить передачу** удаляет промежуточный файл. Если при отмене отправки сервер недоступен, клиент повторит удаление после восстановления связи.

В **Настройках** хозяин видит папку данных и объём хранилища по чатам. Можно отдельно очистить кэш незавершённых отправок, удалить вложения или удалить всю переписку выбранного чата. Действия доступны и для всех чатов сразу.

## Разработка

```sh
npm ci
npm start
npm test
```

`npm run server -- --data путь-до-папки --port 8765` запускает API отдельно от окна. API слушает только `127.0.0.1`.

- `src/server.cjs` обслуживает API и хранит сообщения в SQLite.
- `src/client.cjs` управляет приглашениями, запросами и докачкой.
- `src/tunnel.cjs` запускает Cloudflare Tunnel.
- `src/main.cjs`, `src/preload.cjs` и `src/ui` содержат настольный интерфейс.

Для последующих обновлений закройте PRISM и запустите `update.cmd` в Git-копии проекта. Скрипт подтягивает текущую ветку только при возможности fast-forward и обновляет зависимости. Данные и настройки остаются в прежних папках.
